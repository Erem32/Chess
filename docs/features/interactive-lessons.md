# Interactive lessons

Twenty-four lessons explain piece movement, special moves, king safety and basic tactics. Each includes a single-move exercise and feedback explaining the idea. The server distinguishes illegal moves from legal incorrect answers. Learners can retry or leave, and the marker setting applies. Lessons are grouped by topic and accessible from the Play dashboard.

Lesson content and its format are in [practice data](../../backend/app/data/README.md). See `test_learning_content.py` and the `test:e2e:learning` browser check.
