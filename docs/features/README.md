# Project Helix scope

The university MVP covers online play and short learning activities. The feature references describe the intended behavior and where to change each area:

- [Display and move guidance settings](experience-settings.md)
- [Piece lessons](interactive-lessons.md)
- [Puzzles](puzzles.md)
- [Opening guide](opening-study.md)
- [Teaching examples](teaching-examples.md)
- [Online game and queue feedback](game-setup-board.md)

The backend validates interactive moves and owns game state. Learning positions are separate from online games and statistics. The [project structure](../PROJECT_STRUCTURE.md) and [content guides](../../backend/app/data/) describe the implementation.

## Remaining evaluation

Review the learning content for suitability, then test the learning activities, settings and online queue with a small group on relevant devices. Record participant counts, independent completion, assistance, errors and feedback. The source document's 80% completion and satisfaction figures are provisional targets; report actual counts and avoid generalizing from a small sample.

The source requirements are in the [Project Helix specification](https://docs.google.com/document/d/16WxbylyCP4k2OvAuh3xz5v-DbWU0wTTaF9Sy9nGcxjQ/edit?tab=t.0), sections 2.3 and 3.3. Any expansion beyond this small MVP needs a clear requirement.
