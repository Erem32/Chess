# Display and move guidance settings

Settings are saved in the browser: text size can be normal, large or larger, and legal-move markers can be turned on or off. The default text size is normal and markers are enabled. The choice affects board markers, not move legality. Theme remains a separate browser setting.

See [settings preferences](../../frontend/src/features/settings/preferences.js), [the settings page](../../frontend/src/pages/SettingsPage.jsx), and the `test:e2e:settings` browser check.
